# Roadmap

## Now: v0.1, draft for public comment (until January 10, 2027)

- [x] Publish the draft spec, the JSON Schema and an authoring guide.
- [x] Publish a real example capsule, Plate, and build it unattended with
      Claude Code until a fresh build passes its tests.
- [x] Open this repository for issues, discussions and pull requests.
- [ ] Ask for feedback on developer, web standards and AI-agent forums.
- [ ] Answer every comment.

## Next: v0.2 (early 2027)

- [ ] Publish a summary of every comment and what we did with it.
- [ ] Fold the accepted changes into the spec and credit the people who
      proposed them.
- [ ] Turn the authoring guide's lessons into rules the spec requires: the test
      harness as a deliverable, versions checked at build time, tests that
      look at the rendered app.
- [ ] Start a W3C Community Group for DNApps and move the spec there.

## Then: toward a candidate

- [ ] **Conformance across agents.** The same capsules should pass the same
      tests with at least two independent agents, for example Claude Code and
      Codex.
- [ ] **More reference capsules**, including a large one, so compression can be
      measured on a real app.
- [ ] **Trust**: signed capsules and a way to check where a capsule came from.
- [ ] **A capsule registry**, where people find capsules and fork them.
